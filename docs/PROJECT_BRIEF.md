Stopora is a website for delivery riders and dispatchers in Lagos, Nigeria. A dispatcher enters a start point and up to 12 delivery stops. Stopora returns the order of travel that gives the shortest total road distance, shows it on a map as a numbered route, and reports distance, time and fuel saved compared with the order the dispatcher typed. The rider can open each leg in Google Maps and mark stops as delivered.

Stack: Next.js 15 (App Router) with TypeScript in strict mode, Tailwind CSS, Prisma with PostgreSQL, Leaflet with OpenStreetMap tiles for maps, OpenRouteService for geocoding and road distance matrices, zod for validation, Vitest for unit tests, Playwright for end-to-end tests, GitHub Actions for CI, Vercel for hosting. Use npm.

Build phases:
1 Foundation.
2 Route engine.
3 Maps data (geocoding and distance matrix).
4 Database and API.
5 Dispatcher website.
6 Integration, testing and deployment.
